# Contributing

Thanks for your interest in contributing!

- Open an issue before large changes, so the design can be discussed
  first.
- Keep the library small and simple — formulis is deliberately
  minimal.
- Make sure `dune build @runtest` passes (see [BUILDING.md](BUILDING.md)
  for the toolchain setup).
- Preserve the invariants listed in [HACKING.md](HACKING.md); add or
  adjust test sections for any behaviour change.
- By submitting a contribution you agree to license it under the
  [Apache License 2.0](LICENSE) like the rest of the project.

See also [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
